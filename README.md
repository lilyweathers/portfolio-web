# Lily Clairevelle — Portfolio

A responsive, buildless portfolio made with HTML, CSS, and JavaScript.

Open `index.html` directly in a browser, or serve this directory with a static web server. No installation or build step is needed. Relative links support both local viewing and GitHub Pages under `/portfolio-web/`.

- `index.html`: About, skills, and education
- `projects.html`: Commercial website contributions, GitHub, and Vimeo
- `contact.html`: Contact information and email draft form
- `portrait.jpg`: About portrait
- `styles.css`: Shared responsive design, with Google Fonts and local fallback fonts
- `script.js`: Current footer year and email draft behavior

The contact form opens the visitor’s email app with a prefilled draft. It does not send or store messages. A direct email link is also available.

Existing public site: https://lilyweathers.github.io/portfolio-web/index.html
